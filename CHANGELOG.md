# Changelog

## 2026-11-10

### Mindtrail case study

- Reframed Mindtrail from a research assistant to a personal planner that turns
  school, a job search, and personal goals into one daily plan.
- Role is now "product design, UX, and full-stack engineering"; timeline is
  "Aug 2026 – present".
- Metrics: 100% memory recall on a 45-question held-out test, 0 model calls
  before Today appears, and assistant replies typically under 2 seconds.
  Removed the old "10/10 distractor entries" figure, which overstated the
  result.
- Stack now includes JavaScript, Gmail, Google Calendar, and Canvas.
- Rewrote the problem, target user, and competitors (Todoist and Reminders,
  Notion, ChatGPT) around planning a day across Canvas, Gmail, and Calendar.
- Insight is now four design principles: Today is for doing, never lose what
  someone typed, show where everything came from, and ask before assuming.
- Solution is now a set of design decisions: Rethinking Today, Plans that stay
  readable, An assistant that knows you, Showing the source, Designing for
  failure, and Motion and detail.
- Added four screenshots taken on sample data with made-up companies: Today, a
  step's route, the assistant asking first, and a job to-do's source card.
- Corrected outdated claims: changes now apply as you ask (deletions still wait
  for a yes), screenshots can be read, and an incorrect command example was
  removed.
